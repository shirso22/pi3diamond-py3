pi3diamond run manual - Shirso

Do this in your Command Prompt

First, navigate to your pi3diamond directory, then:

py -3.13 -m venv venv (The version can be something other than 3.13 too, 3.13 is the latest Python, select as appropriate, the last venv is the folder name for this virtual environment, set it whatever you want. This will create a folder called venv in your root)
venv\Scripts\activate (Launches the venv)
pip install -r requirements.txt
set ETS_TOOLKIT=qt (Visualization tools set appropriately)

Now you can try running pi3dummy, etc and see what happens
